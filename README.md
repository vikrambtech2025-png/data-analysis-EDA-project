# Amazon Financial & E-Commerce EDA (2025)

Exploratory data analysis of **Amazon financial data and e-commerce sales for 2025** — quarterly revenue summaries, customer metrics, and sales insights, delivered as a Python analysis script, a complete Jupyter notebook, and structured project guides.

## Contents

| File | Description |
|---|---|
| `Amazon_Financial_Analysis_2025.py` | End-to-end Python analysis: load, clean, and summarize Amazon 2025 financial data |
| `E_commerce_Sales_EDA_Complete.ipynb` | Step-by-step EDA notebook for e-commerce sales data (univariate/bivariate analysis, visualizations) |
| `amazon_financial_data_2025.csv` · `amazon_2025_quarterly_summary.csv` | Source and derived financial datasets |
| `customer_metrics.csv` · `ecommerce_data_cleaned.csv` | Customer- and product-level analysis tables |
| `QUICK_START_GUIDE.md` · `AMAZON_ANALYSIS_GUIDE.md` · `PROJECT_COMPLETE_SUMMARY.md` · `README_EDA_Workflow_Guide.md` | Documentation for setup, workflow, and findings |

## Tech stack

- **Data:** pandas, NumPy · **Visualization:** Matplotlib, Seaborn, Plotly
- **Statistics & reports:** SciPy, scikit-learn, fpdf2 (PDF reports), openpyxl

## Getting started

```bash
pip install -r requirements.txt
python Amazon_Financial_Analysis_2025.py        # run the full analysis
jupyter notebook E_commerce_Sales_EDA_Complete.ipynb
```
